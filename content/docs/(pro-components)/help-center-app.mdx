## Introduction

**Help Center App** includes:

- **Search**: Filter articles by title, excerpt, or category label.
- **Categories**: Sidebar on large screens and a compact category select on small screens.
- **Article grid**: Card layout with read time and “last updated” hints.
- **FAQ**: Single-expand accordion for common questions.
- **Support CTAs**: Email, live chat, and priority resources in a three-column row.

Uses Button, Input, Card, Badge, Accordion, Select, and Separator patterns. State for search and active category lives in Zustand (`zustand`).
