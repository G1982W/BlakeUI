## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/components/ui/popover";
```

```tsx
<Popover>
  <PopoverTrigger asChild>
    <Button>Open</Button>
  </PopoverTrigger>
  <PopoverContent>
    <p>Popover content</p>
  </PopoverContent>
</Popover>
```

## API Reference

### Popover

Root component that manages the open/close state.

### PopoverTrigger

The element that toggles the popover. Use `asChild` to delegate rendering to a child element.

### PopoverContent

The floating content panel. Renders in a portal.

| Prop         | Type                             | Default  | Description                             |
| ------------ | -------------------------------- | -------- | --------------------------------------- |
| `side`       | `top \| right \| bottom \| left` | `bottom` | Which side of the trigger to render on. |
| `align`      | `start \| center \| end`         | `center` | Alignment relative to the trigger.      |
| `sideOffset` | `number`                         | `4`      | Distance in pixels from the trigger.    |

### PopoverAnchor

Optional. Use as an alternative anchor point instead of the trigger element.
